Knowledge MCP offline appliance

An air-gapped Java modular monolith that ingests the LuciadLightspeed SDK docs into an immutable index and serves grounded, cited answers to coding agents over MCP. Pick a flow and step through it — the mode toggle switches between the hardened serving image and the separate training-ingest image (AD-27 / AD-28).

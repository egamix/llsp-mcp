## What went well

1. **Enforcement over documentation.** AD-1 (dependency direction) and AD-9 (zero egress) fail the build rather than living in prose. Both were validated by negative tests — a planted forbidden edge and a planted egress attempt. This is the strongest habit in the epic.
2. **Scope discipline held.** Every story carried an explicit "do not build" list and honored it. Deferred approval gates (SQLite DDL, Lucene field set, MCP JSON schemas, embedding model) were left as stubs, not invented ahead of their epic.
3. **Durable mechanism choices.** The egress guard deliberately avoided `SecurityManager` (removed by JEP 486 on JDK 24+ — the "silent no-op guard" trap) in favor of a supported SPI that survives the still-open JDK-version question.
4. **Code review found real defects, not nits.** Every story's adversarial review caught genuine bugs (see below), all fixed in-review.
5. **Deferred work tracked systematically** in `deferred-work.md` with file/line and a reason per item.

## Recurring problems (systemic)

1. **Tests that pass vacuously — appeared in 3 of 4 stories.** 1.3's determinism test ran over two *different* input dirs (assertion held trivially); 1.3's "regardless of policy" AC was only half-tested (fail-fast branch missing); 1.4 required pinned known-answer hashes to prevent silent recipe drift. Reviews caught all of these — the lesson is to write assertions adversarially the first time, not only at review. **Top lesson of the epic.**
2. **Seams defined but not wired.** 1.2's `TrainingIngestSeam` was described as "routed to" but never actually called; caught in review. Watch for "documented but not connected" in stub-heavy work.
3. **Windows path / edge-case handling repeatedly incomplete.** UNC, `\\?\UNC\`, extended-length device paths, empty-string option values, symlink/junction real-path resolution — a steady stream across 1.2 and 1.4. Some fixed, some deferred. Epic 2 touches real file trees, so this keeps mattering.
4. **Environment friction, documented but recurring:** corporate-proxy PKIX (`GRADLE_OPTS=-Djavax.net.ssl.trustStoreType=Windows-ROOT`) and `python` vs `python3` on Windows. Documented per-story; worth consolidating into one build-setup doc.
